# Artificial-Neural-Network-ANN-
This project shows how to use Deep Learning techniques to create an Artificial Neural Network (ANN) to solve classification and prediction tasks. Python and well-known machine learning frameworks are used in the model's construction to extract intricate patterns from data and produce precise forecasts.

Data preprocessing and feature engineering
Neural network architecture with input, hidden, and output layers
Model training using backpropagation and gradient descent
Performance evaluation using accuracy, precision, recall, and F1-score
Visualization of training and validation results
